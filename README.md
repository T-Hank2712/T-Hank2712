A backend system for managing movie theaters, showtimes, seat reservations and ticket booking.

* ⚙️ Built with **C# and ASP.NET Core**
* 🏗️ Applied multi-layered architecture
* 🗄️ Managed data with Entity Framework Core and SQL Server
* 🔐 Implemented authentication and authorization using JWT
* ⚡ Used Redis for temporary seat locking
* 🎟️ Developed showtime, booking and invoice management features

An AI-powered platform that analyzes packaged food labels and provides nutritional information.

* 📷 Extracts information from food labels using OCR and KIE
* 🌐 Provides backend services through RESTful APIs
* 🧬 Uses Neo4j Knowledge Graph for nutrition knowledge
* ☁️ Integrates AWS S3 for image storage
* 🐳 Deploys backend and AI services with Docker
* 📱 Includes an iOS application developed with SwiftUI
